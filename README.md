A PC game inspired by the classic 2005 mobile game Tower Bloxx.  
Drop towers. Stack them perfectly. Build as high as you can.

## How To Play

**1.** Launch the game and press **Play**

**2.** The dropper moves automatically left and right

**3.** Press **Space** to drop the tower

**4.** Try to stack it as **centered** as possible — if it falls off the edge, it's game over!

**5.** The game is infinite — keep stacking and beat your high score!

### Controls

<kbd>Space</kbd> — Drop tower  
<kbd>Esc</kbd> — Pause
